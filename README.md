# Темірадам (TemirAdam)
**AI Assistant for Linux**

*Это мой собственный личный ИИ-агент для повседневной жизни. Он умеет распознавать голос, отвечать голосом и выполнять полезные действия на моём компьютере.*

</div>

---

## 🧐 Что это такое?

**Темірадам** — это полностью локальный, приватный голосовой помощник (в стиле JARVIS), созданный специально для моей среды Linux. Он слушает микрофон, ждёт ключевое слово («Темірадам»), проверяет мой голос (чтобы никто другой не мог им управлять) и выполняет команды или отвечает на сложные вопросы с помощью локальных нейросетей (LLM).

Всё работает прямо на моём компьютере без интернета. Никакие аудиозаписи или текстовые данные не отправляются на сторонние серверы.

---

## 🛠 Моя настройка (My Setup)

Этот проект разрабатывался под моё конкретное рабочее окружение, поэтому он может не работать "из коробки" на Windows или macOS.

* **ОС**: CachyOS (Arch Linux)
* **Аудио**: PipeWire + WirePlumber
* **Интерфейс (UI)**: Quickshell + Hyprland (Wayland)
* **Железо**: AMD Ryzen 7 7435HS, NVIDIA RTX 4060 (8GB VRAM), 16GB RAM

> [!NOTE]
> Если вы сидите на Windows — этот проект вам, скорее всего, не подойдёт, так как он сильно завязан на специфичные утилиты Linux (D-Bus, `playerctl`, `wpctl`, `quickshell`).

## ⚡ Что именно он делает для меня?

Вместо того чтобы давать ИИ полный, опасный доступ к терминалу, я ограничил его строгим набором действий (Tool System), которые он может делать.

Вот что он умеет:
1. **Интеграция с UI (Quickshell)**: Ассистент общается с моими виджетами через IPC (`qs ipc call`). Я вижу на экране, когда он меня слушает, когда думает, и какую именно модель использует.
2. **Управление музыкой (Spotify)**: Я могу сказать *"Темірадам, включи Linkin Park Numb"* — он сам откроет Spotify в фоне и через D-Bus/MPRIS запустит нужный трек. Умеет ставить на паузу и переключать треки.
3. **Управление системой**: Настройка громкости (через `wpctl` / WirePlumber), включение/выключение звука, время, дата.
4. **Запуск приложений**: Может открывать браузер, терминал или нужные программы.
5. **Поиск на YouTube**: *"Найди на ютубе музыку для программирования"* — открывает браузер с готовым запросом.
6. **Умные ответы**: Если я задаю сложный вопрос по программированию или Linux, он отвечает развёрнуто голосом (на русском или казахском языках).

## 🧠 Трёхуровневая система LLM (Умный подход к ресурсам)

У меня всего 8 ГБ видеопамяти, поэтому Темірадам не держит огромную нейросеть в памяти постоянно. Я реализовал **трёхуровневую архитектуру**:

* **Уровень 0 (Fast Matcher)**: Простые команды (*"Пауза"*, *"Громкость 30"*). LLM вообще **не загружается**. Работают мгновенные регулярные выражения. Память: ~0 ГБ.
* **Уровень 1 (EASY - 0.5B)**: Простые просьбы (*"Открой Spotify"*). Загружается микро-модель `qwen2.5:0.5b`. Память: ~0.5 ГБ.
* **Уровень 2 (MEDIUM - 4B)**: Запросы с контекстом (*"Включи что-нибудь спокойное"*). Загружается `qwen3:4b`. Память: ~2.5 ГБ.
* **Уровень 3 (HARD - 8B)**: Сложные вопросы по коду или системе. Только тогда загружается большая `qwen3:8b` (забирая ~5-6 ГБ).

Всё это разруливается мгновенным локальным Роутером. Как только задача выполнена — **любая модель мгновенно выгружается из памяти**, возвращая потребление VRAM к нулю.

## 📦 Требования и установка (Requirements)

Если вы всё же хотите запустить это на своём Linux:

### Зависимости системы:
* `python3` (>= 3.10)
* `ollama` (запущенный локально сервис)
* `pipewire` и `wireplumber` (обязательно для захвата аудио и контроля громкости)
* `playerctl` (для управления плеерами по D-Bus)
* `quickshell` (опционально, для UI виджетов)

### Установка:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/вашучастник/TemirAdam.git
   cd TemirAdam
   ```
2. Запустите автоматический скрипт установки (установит pip-пакеты и скачает модели Ollama):
   ```bash
   ./setup.sh
   ```
3. Запишите свой голосовой профиль (защита от чужих голосов):
   ```bash
   python3 main.py enroll
   ```
4. Запустите агента (или добавьте его в автозагрузку через systemd):
   ```bash
   python3 main.py run
   ```
